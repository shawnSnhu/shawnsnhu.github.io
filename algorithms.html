Artifact narrative

Selection and improvement

For this milestone, I enhanced a C++ course planning application that I created in December 2025 for my Data Structures and Algorithms course. The original program read course information from a CSV file and stored the records in an unordered map. Through a menu, a user could load a file, display the course list, or search for a course and view its prerequisites. The list was sorted by course number, which met the original requirements, but it did not create a sequence based on prerequisites.

I kept the unordered map for looking up individual courses and added a directed graph for representing the relationships between them. Each course is a vertex, and an edge points from a prerequisite to the course that depends on it. An adjacency list stores the edges, while an indegree count tracks how many prerequisites remain for each course. Kahn's topological sorting algorithm uses those counts to create an order in which prerequisites appear first.

Course outcomes and skills

The enhancement demonstrates the use of an appropriate data structure and algorithm while accounting for design trade-offs. Building the graph and generating the course order both take O(V + E) time, where V represents the courses and E represents the prerequisite connections. I chose a regular queue instead of a priority queue because the program only needs a valid course order, and the regular queue preserves the simpler linear runtime.

Outcome connection: This work most directly supports Outcome 3 because it applies graph structures, a topological sort, runtime analysis, and an explicit queue trade-off to solve the course-ordering problem.

Reflection and trade-offs

The most important thing I learned was how the direction of a graph affects the sorting process. Edges need to point from prerequisites to dependent courses so that completing one course reduces the count for the correct courses. Testing also required a different approach because several valid course orders can exist. Instead of expecting one exact list, the tests confirm that every prerequisite appears before the course that requires it.

I considered adding semester planning, credit limits, or database storage. Those features could be useful, but they would move the artifact beyond the algorithms and data structures goal. The instructor described the submitted coding as sound and did not request corrections, so the final revision preserves the algorithm and focuses on clear documentation and presentation.
